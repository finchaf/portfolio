What a machine could check was not checked by eye. 89 of the 234 rules carried the #script mark. Scripts ran until their output was empty, then every frame was viewed large.

| Script             | What it caught                                                                       |
| ------------------ | ------------------------------------------------------------------------------------ |
| `audit.js`         | Elements pressed to an edge, stray opacity, clipped shadows, fills without variables |
| `layout-audit.js`  | Frame geometry: margins, steps, sizes                                                |
| `check-screens.py` | The map: every brief feature has a one-tap entry                                     |
| `typo-scan.js`     | Hanging prepositions and single-word lines                                           |

A note that could be counted got a check in a script. The rest went to the [[critic|critic]].
