Несколько настоящих правил из [[checklists|чеклистов]], формулировки сокращены. Рядом с номером: #повтор значит, что замечание звучало дважды, #скрипт значит, что пункт проверял [[audit|аудит]].

- `sheets-menus#1` Меню из кнопки встаёт на место кнопки: правый верхний угол меню совпадает с правым верхним углом кнопки. Меню не выпадает под кнопкой. #повтор #скрипт
- `navigation#3` У каждого видимого контрола видно, что будет по тапу. Кнопка, для которой нечего показать, лишняя. #повтор #скрипт
- `sheets-menus#2` В шапках шитов нет текстовых Cancel и Done: круглые символы, ✕ слева, ✓ справа акцентной заливкой. #скрипт
- `layout#5` Одиночная кнопка-глиф в тулбаре круглая, 44 × 44. Пилюля только у группы из двух. #скрипт
- `layout#6` Мелкая графика строго 1 : 1: бегунки, точки, радио, кольца. #скрипт
- `states#4` Пустое состояние стоит по центру свободной области, а не прижато к верху. #скрипт
- `visual#4` Один акцент на экран. Цветом выделяется только главное действие.
- `texts#13` Свой термин объяснён в интерфейсе там, где встречается впервые.
