# Contributing

This is a personal site: its texts, design and decisions are one person's work, so pull requests are
not taken. The code is open to read and to learn from (see [LICENSE](LICENSE) and [NOTICE](NOTICE)).

What helps:

- **A bug on the site:** open an [issue](https://github.com/finchaf/portfolio/issues/new/choose) with
  the address, the browser and what you saw. A screenshot or a short recording saves a lot of guessing.
- **A question about how something is built:** ask in
  [Discussions](https://github.com/finchaf/portfolio/discussions). The reasoning behind most choices is
  already in [`docs/01-architecture/decisions/`](docs/01-architecture/decisions/README.md), in Russian.
- **A security problem:** privately, as [SECURITY.md](SECURITY.md) says, never in an issue.

Running the site locally is described in the [README](README.md#working-here).
