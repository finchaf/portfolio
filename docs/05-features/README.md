# Страницы и адреса

**Статус:** реализовано — каркас страниц и главная 30.10.2026, содержание остальных страниц приходит отдельно

> Какие адреса отвечает сайт и как устроены страницы технически. Открывать перед новым маршрутом.

| Адрес | Что |
| --- | --- |
| `/` | `302` на `/ru` или `/en`: выбирает Caddy |
| `/ru`, `/en` | Главная |
| `/ru/pora-na-paru`, `/en/pora-na-paru` | Пора на пару |
| `/ru/flow`, `/en/flow` | Флоу: работа с агентами |
| `/ru/projects`, `/en/projects` | Проекты |
| Любой другой | `404` со страницей на двух языках, `noindex` |

Позже добавятся резюме, `/cv/ru.pdf` и `/cv/en.pdf`, и песочница эффектов `/lab` с `noindex`.

Все страницы есть на обоих языках. Реестр страниц — `src/lib/pages.ts`. Правило языка то же, что в
вебе продукта: первый язык браузера русский, заголовка нет или он пуст — `ru`, иначе `en`; ответ `302` с
`Vary: Accept-Language`, строка запроса сохраняется, cookie нет. Адрес с косой чертой на конце — `308`
на адрес без неё. Всё это держит гейт Addresses.

У каждой страницы:

- свой `title`, `description` и общая картинка для ссылок `public/og.png`;
- `canonical` и `hreflang` `ru`, `en`, `x-default` на `/`;
- место в `sitemap.xml`.

Главная отдаёт структурированные данные `Person`: `src/features/home/person-data.tsx`.

Переключатель языка — ссылка на ту же страницу с другим префиксом. Смена страницы — плавный переход
`<ViewTransition>`; при `prefers-reduced-motion` он мгновенный. Карточка на главной и верх страницы, которую
она открывает, носят одно имя `world-<имя>`, поэтому карточка перетекает в страницу: `src/ui/world-hero.tsx`.

На телефоне и планшете разделы уходят в панель внизу, а тема и язык складываются во всплывающее окно:
атрибут `popover`, работает без скрипта. Кнопка «Написать» — обычная ссылка на Telegram.

## Главная

Секции идут сверху вниз, направление движения меняется от секции к секции: первый экран, история на
колесе, дизайн → код в глубину, кейсы стопкой, опыт, финал. Шаги истории — `STEPS` в
`src/features/home/story.tsx`. Без JavaScript и при уменьшенном движении это обычная страница.
