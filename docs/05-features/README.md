# Страницы и адреса

**Статус:** спецификация — кода сайта нет на 30.10.2026

> Какие адреса отвечает сайт и как устроены страницы технически. Открывать перед новым маршрутом.

| Адрес | Что |
| --- | --- |
| `/` | `302` на `/ru` или `/en`: выбирает Caddy |
| `/ru`, `/en` | Главная |
| `/ru/work/<slug>`, `/en/work/<slug>` | Работа |
| `/ru/cv`, `/en/cv` | Резюме на странице |
| `/cv/ru.pdf`, `/cv/en.pdf` | Резюме в PDF, собирается при сборке из страницы |
| `/lab` | Песочница эффектов, `noindex` |
| `/404.html` | Ответ на неизвестный адрес, на двух языках |

Все страницы есть на обоих языках. Правило языка то же, что в вебе продукта: первый язык браузера
русский или заголовка нет — `ru`, иначе `en`; ответ `302` с `Vary: Accept-Language`, cookie нет.

У каждой страницы:

- свой `title`, `description` и картинка для ссылок;
- `canonical` и `hreflang` `ru`, `en`, `x-default` на `/`;
- структурированные данные `Person` на главной;
- место в `sitemap.xml`, кроме `/lab`.

Переключатель языка — ссылка на ту же страницу с другим префиксом. Тема, если она будет, хранится в
`localStorage` и ставится скриптом до первой отрисовки.
