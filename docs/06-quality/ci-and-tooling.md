# Качество и инструменты

**Статус:** спецификация — работают гейты Docs и Public, остальные приходят с каркасом

> Что проверяется перед коммитом и в CI, какие бюджеты и как выпускается сайт. Открывать перед новым
> гейтом и когда что-то красное. Решение — [ADR-0007](../01-architecture/decisions/0007-process-and-gates.md).

## Команда

`python3 scripts/check.py` — все гейты, таблица в конце со всеми упавшими. `--fast` пропускает сборку
и браузер. CI запускает ту же команду на PR.

## Гейты

| Гейт | Что держит |
| --- | --- |
| Docs | Ссылки и якоря, связность, врезки, язык, статусы, журнал ADR |
| Public | Нет ссылок в приватную часть; локально — нет слов из её списка в файлах и коммитах |
| Format | Prettier |
| Lint | ESLint, `jsx-a11y`, правила Next.js |
| Types | `tsc --noEmit`, строгий режим |
| Unit | Vitest |
| Content | Одинаковые ключи и MDX на обоих языках |
| Build | `next build` даёт ровно маршруты из `expected-build.json`, все статические |
| Bundle | Бюджеты ниже |
| Addresses | Собранный сайт за настоящим Caddy: редиректы, 404, кэш, CSP без нарушений |
| A11y | axe на каждой странице |
| SEO | `title`, `description`, `canonical`, `hreflang`, sitemap, robots |
| Motion | Без JavaScript и при `prefers-reduced-motion` весь контент виден |

Для Addresses нужен Docker: Colima на машине, `colima start`. Он видит только домашнюю папку.

## Бюджеты

Основа замера — прототип 30.10.2026, gzip уровня 9: база Next.js и React 171 КБ, Motion 45 КБ, GSAP с
плагинами и Lenis 52 КБ.

| Что | Бюджет |
| --- | --- |
| JavaScript первой загрузки на страницу | до 280 КБ gzip: база, Motion, GSAP и 12 КБ своего кода |
| 3D, большие демонстрации | вне первой загрузки, отдельным куском |
| LCP на эмуляции телефона | до 2,5 с |
| CLS | до 0,05 |
| Картинка первого экрана | до 200 КБ |
| Первая страница целиком, без видео | до 1,5 МБ |

Бюджет меняется только правкой `expected-build.json` с объяснением в коммите.

## Браузеры

Chromium 111+, Safari 16.4+, Firefox 128+. Гейты идут в Chromium. Safari и iPhone проверяются руками
перед каждым большим эффектом: на них чаще всего ломаются анимация, видео и WebGL. Смотреть надо сборку,
а не `next dev`.

## CI

- `gates.yml` — `check.py` на PR, отдельно статика и браузер.
- `commits.yml` — каждый коммит PR через тот же `.githooks/commit-msg`.
- Dependabot — зависимости и действия.
- GitHub — Secret scanning с запретом пуша и закрытые сообщения об уязвимостях.

В открытом репозитории минуты не считаются. Ключей продакшена в CI нет, и выкатка идёт с ноутбука
([ADR-0005](../01-architecture/decisions/0005-atomic-deploy-from-laptop.md)).

## Коммиты

Conventional Commits, тема до 72 знаков, тело до 100, подпись SSH-ключом. Как код попадает в `main` —
[ADR-0007](../01-architecture/decisions/0007-process-and-gates.md). Правила `main` требуют подписи, которую подтвердил GitHub. Локальная буква `G` в `git log --format=%G?`
этого не доказывает: ключ должен быть добавлен в аккаунт именно как ключ подписи, а ключ для входа не
считается. Проверка — `gh api users/zibliclub/ssh_signing_keys`. Хук включается один раз на клон:

```
git config core.hooksPath .githooks
```
