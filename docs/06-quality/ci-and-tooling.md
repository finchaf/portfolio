# Качество и инструменты

**Статус:** реализовано — все гейты работают с 30.10.2026

> Что проверяется перед коммитом и в CI, какие бюджеты и как выпускается сайт. Открывать перед новым
> гейтом и когда что-то красное. Решение — [ADR-0007](../01-architecture/decisions/0007-process-and-gates.md).

## Команда

`python3 scripts/check.py` — все гейты, таблица в конце со всеми упавшими. `--fast` пропускает сборку
и браузер. CI запускает ту же команду на PR.

Посмотреть сайт: `pnpm dev` с горячей перезагрузкой на `http://localhost:3000`, либо `pnpm build` и
`pnpm preview` — сборка за настоящим Caddy на `http://127.0.0.1:8090`.

## Гейты

| Гейт | Что держит |
| --- | --- |
| Docs | Ссылки и якоря, связность, врезки, язык, статусы, журнал ADR |
| Public | Нет ссылок в приватную часть; локально — нет слов из её списка в файлах и коммитах. Слово из её второго списка можно только в `messages/` |
| Format | Prettier |
| Lint | ESLint, `jsx-a11y`, правила Next.js |
| Types | `tsc --noEmit`, строгий режим |
| Unit | Vitest, в том числе контракт тем и контраст |
| Content | Одинаковые файлы и ключи на обоих языках, ключи в `camelCase`, значения не пусты |
| Build | Сборка даёт ровно страницы из `expected-build.json`, у каждой есть сжатые копии |
| Bundle | Бюджеты ниже |
| Addresses | Сборка за настоящим Caddy: язык, редиректы, 404, кэш, сжатие, CSP без нарушений, переходы без перезагрузки |
| A11y | axe на каждой странице и на 404, ссылка «К содержанию» с клавиатуры |
| SEO | `title`, `description`, `canonical`, `hreflang`, sitemap, robots |
| Motion | Без JavaScript и при `prefers-reduced-motion` весь контент виден; линза и совпадение слоя кода с дизайном, сборка первого экрана, сцены, посадка глав истории на пяти размерах экрана и главы «Работ», капсула и смена обшивки в главах, код над именем на разной высоте, курсор-точка, футер, телефонная ширина |
| Themes | Цвет и шрифт каждой страницы в обоих режимах, выбор режима, нужные шрифты, axe в обоих режимах |

Для браузерных гейтов нужен Docker: `colima start`. Образ Caddy закреплён тем же digest, что на проде, а
`scripts/serve.py` кладёт сборку туда же, куда на сервере. Colima видит только домашнюю папку.

Проверяйте, что гейт умеет падать: каркас проверен намеренным импортом между фичами, текстом в разметке
и лишним ключом.

## Бюджеты

Замер на 31.10.2026, gzip уровня 9 (`python3 scripts/check_bundle.py`): главная 245,2 КБ с GSAP и
ScrollTrigger, остальные страницы 187,9 КБ. По прототипу Motion добавит 45 КБ.

| Что | Бюджет |
| --- | --- |
| JavaScript первой загрузки на страницу | до 280 КБ gzip |
| 3D, большие демонстрации | вне первой загрузки, отдельным куском |
| LCP на эмуляции телефона | до 2,5 с |
| CLS | до 0,05 |
| Картинка первого экрана | до 200 КБ |
| Первая страница целиком, без видео | до 1,5 МБ |

Бюджет меняется только правкой `expected-build.json` с объяснением в коммите.

## Браузеры

Chromium 111+, Safari 16.4+, Firefox 128+. Гейты идут в Chromium. Firefox, Safari и iPhone проверяются руками
перед каждым большим эффектом: на них чаще всего ломаются анимация, видео и WebGL. Смотреть надо сборку,
а не `next dev`. Быстрая проверка до этого — движок WebKit из Playwright: он уже поймал схлопнутую 3D-сцену,
но настоящий Safari не заменяет. Firefox проверяется в настоящем браузере: он уже ломал тонкую штриховку, которую
Chromium рисует чисто. Встроенный в Playwright Firefox на macOS 27 не запускается (31.10.2026), зато установленный
Zen управляется по Marionette: `--headless --marionette -profile <временная папка>`.

## CI

- `gates.yml` — `check.py` на PR, две задачи: Static gates и Build and browser gates.
- `commits.yml` — каждый коммит PR через тот же `.githooks/commit-msg`.
- Dependabot — зависимости и действия.
- GitHub — Secret scanning с запретом пуша и закрытые сообщения об уязвимостях.

В открытом репозитории минуты не считаются. Ключей продакшена в CI нет, и выкатка идёт с ноутбука
([ADR-0005](../01-architecture/decisions/0005-atomic-deploy-from-laptop.md)).

## Коммиты

Conventional Commits, тема до 72 знаков, тело до 100, подпись SSH-ключом. Как код попадает в `main` —
[ADR-0007](../01-architecture/decisions/0007-process-and-gates.md). Правила `main` требуют подписи, которую подтвердил GitHub. Локальная буква `G` в `git log --format=%G?`
этого не доказывает: ключ должен быть добавлен в аккаунт именно как ключ подписи, а ключ для входа не
считается. Проверка — `gh api users/finchaf/ssh_signing_keys`. Хук включается один раз на клон:

```
git config core.hooksPath .githooks
```
