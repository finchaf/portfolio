# ADR-0003: Стек как в вебе «Пора на пару», одно приложение без монорепо

- **Статус:** принят
- **Дата:** 2026-10-30

> На чём пишется сайт, что перенято из веба «Пора на пару» и что сознательно нет. Читать перед
> выбором библиотеки.

## Контекст

Владелец хочет работать как в вебе продукта и иметь полный контроль: разбирать понравившиеся приёмы
и переписывать их под себя. Один разработчик, одно приложение. Конструкторы отпадают сразу: контроль
ограничен, а код — часть портфолио.

## Варианты

**Фреймворк.**

- **Next.js, React, TypeScript.** Те же знания, приёмы и инструменты. Общий макет живёт между
  страницами, поэтому 3D-сцена и звук переживают переход. Цена: базовый JavaScript — 171 КБ gzip
  (замер прототипа, 30.10.2026).
- **Astro.** Меньше JavaScript там, где страница статична, встроенные переходы. Но почти каждая
  страница здесь будет интерактивной, острова на React всё равно подтянут React, а опыт и готовые
  решения веба не переносятся. Лучший выбор для статей, не для этого сайта.

**Раскладка.** Монорепо Turborepo оправдано в вебе несколькими приложениями и общими пакетами. Здесь
приложение одно, и слой задач ничего не даст.

## Решение

Как в вебе:

| Что | Чем |
| --- | --- |
| Фреймворк | Next.js 16, App Router, React 19, TypeScript в строгом режиме |
| Стили | Tailwind CSS 4, токены в CSS-переменных, OKLCH, `light-dark()` |
| Компоненты | shadcn/ui на Radix, исходным кодом и только по мере надобности |
| Языки | `next-intl`, префикс в адресе, текст переводится на сервере, без провайдера |
| Длинные тексты | MDX: кейсы со встроенными демонстрациями |
| Шрифты | `next/font/local`, только со своего сервера |
| Пакеты | pnpm, версия Node в `devEngines`, точные версии, установка не раньше суток после релиза, скрипты зависимостей выключены |
| Качество | ESLint, Prettier, Vitest, Playwright, axe |

Иначе, чем в вебе:

- **Одно приложение в корне**, без Turborepo и `packages/`. Триггер — появление второго приложения.
- **Без реестра, образов и Trivy:** контейнера нет ([ADR-0002](0002-static-export-on-caddy.md)).
- **Без `old_engines.py`:** читателю нужен современный браузер, а минимум — это минимум Tailwind 4:
  Chromium 111+, Safari 16.4+, Firefox 128+.
- **Файлы не копируются из веба продукта.** Перенимаются приёмы и настройки. Код продукта в открытый
  репозиторий не попадает: это не наше, чтобы открывать.

Точные версии — в `package.json` с каркаса. Старт — версии, проверенные в прототипе: Next.js 16.4.3,
React 19.3, Tailwind 4.3.3, next-intl 4.14. Мажорное обновление — отдельная задача.

## Последствия

**Хорошее:** нулевая цена переключения между проектами, проверенные решения.

**Плохое:** 171 КБ базового JavaScript. Бюджет страницы учитывает это
([качество](../../06-quality/ci-and-tooling.md#бюджеты)).

**Триггер пересмотра:** базовый JavaScript мешает показателям загрузки на телефоне при выполненном
бюджете.
