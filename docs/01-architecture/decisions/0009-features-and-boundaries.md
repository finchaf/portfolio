# ADR-0009: Страница — это фича, папки `src/` разделены границами импорта

- **Статус:** принят
- **Дата:** 2026-10-30

> Как разложен код сайта, кто кого может импортировать и почему страницы не делят код напрямую.
> Читать перед новой страницей и перед импортом из соседней папки.

## Контекст

Сайт многостраничный, и каждая страница будет своим миром со своей механикой: неделя, терминал с
базой заметок, холст. Каждая вырастет в отдельный движок. В вебе продукта разделение держат пакеты и
Turborepo, здесь приложение одно ([ADR-0003](0003-stack-as-in-the-web.md)).

## Варианты

- **Всё в `components/`.** Просто на старте, но через месяц неделя и холст срастутся через общие файлы.
- **Монорепо с пакетом на страницу.** Границы железные, но ради одного приложения это лишний слой.
- **Папка на фичу и границы линтером.** Те же правила в одном приложении.

## Решение

Выбран третий вариант.

- **`src/features/<страница>/`** держит всё, что нужно одной странице.
- **Файл маршрута тонкий:** метаданные и одна фича.
- **Импорты идут только вниз:**

  | Папка | Может импортировать |
  | --- | --- |
  | `app/` | всё ниже |
  | `features/` | `ui/`, `i18n/`, `lib/`; другую фичу и `shell/` нельзя |
  | `shell/` | `ui/`, `i18n/`, `lib/` |
  | `ui/`, `i18n/`, `lib/` | друг друга, но не то, что построено на них |

- **Правило держит ESLint** (`import/no-restricted-paths` в `eslint.config.mjs`), нарушение красит гейт
  Lint. Проверено намеренным нарушением.
- **Реестр страниц один:** `src/lib/pages.ts`. Из него строятся шапка, карта сайта, метаданные и
  браузерные гейты.
- **Адрес страницы о работе с агентами — `/flow`, название «Флоу»** (владелец, 30.10.2026). Страница
  названа по методу, а не по месту работы.
- **Библиотека приходит с первым кодом, которому нужна.** MDX, Motion, GSAP и shadcn/ui в каркас не
  входят, решения [ADR-0003](0003-stack-as-in-the-web.md) и [ADR-0004](0004-motion-stack.md) остаются в
  силе.

## Последствия

**Хорошее:** фича удаляется или переписывается одной папкой, и страницы не ломают друг друга.

**Плохое:** общий код нельзя взять из соседней фичи, его надо сначала опустить вниз. Это сознательная цена.

**Триггер пересмотра:** второе приложение в репозитории — пакеты и монорепо, как в вебе.
