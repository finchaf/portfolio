# Движение

**Статус:** спецификация — значения токенов задаёт дизайн

> Как добавить эффект: каким инструментом, как перенести чужой приём, что обязательно проверить.
> Открывать перед любой анимацией. Почему именно эти инструменты —
> [ADR-0004](../01-architecture/decisions/0004-motion-stack.md).

## Что чем делать

| Эффект | Инструмент |
| --- | --- |
| Наведение, фокус, нажатие | CSS |
| Появление при прокрутке без привязки к положению | CSS, `animation-timeline`, иначе Motion |
| Переход между страницами, общий элемент | `<ViewTransition>` |
| Раскрытие, перестановка, смена раскладки | Motion: `layout`, `layoutId` |
| Перетаскивание, жесты, пружины | Motion |
| Закрепление, сцена на скролле, сложный таймлайн | GSAP, ScrollTrigger |
| Разбивка текста на буквы и строки | GSAP, SplitText |
| Плавная смена раскладки вне React | GSAP, Flip |
| 3D, шейдеры, частицы | three.js через React Three Fiber |
| Плавная прокрутка | Lenis, только на десктопе |

Сомневаешься — бери инструмент выше по таблице.

## Как переносить референс

1. **Снять:** записать экран и открыть панель Animations в DevTools. `document.getAnimations()`
   покажет длительность и кривую.
2. **Описать:** триггер, что двигается, длительность, кривая, что на телефоне.
3. **Выбрать** инструмент по таблице.
4. **Написать заново** нашими токенами.
5. **Проверить** по списку ниже.
6. **Записать** источник приёма в описании PR.

Берём идею и ощущение, а не код. Минифицированный код, шейдеры, модели и картинки чужого сайта не
копируются даже частично: у них есть авторы, а репозиторий будет открыт.

## Токены

Длительности и кривые живут в одном месте: `src/motion/tokens.ts` и CSS-переменные с теми же
значениями. Значений в коде эффекта нет. Значения решает дизайн.

## Обязательно для каждого эффекта

- **Анимируются `transform` и `opacity`.** `width`, `top` и тени в цикле ломают плавность.
- **`prefers-reduced-motion`:** движение заменяется мгновенным или мягким появлением, контент не теряется.
- **Без JavaScript всё видно.** Начальное скрытое состояние ставит скрипт, а не CSS в HTML.
- **Телефон:** нет наведения, упрощённая сцена или её нет совсем.
- **Очистка:** эффекты снимаются при уходе со страницы. GSAP — через `useGSAP`.
- **Прокрутка не перехватывается** на тач-устройствах, клавиатура работает всегда.
- **60 кадров в секунду** на среднем телефоне: проверяется в DevTools с замедлением CPU в 4 раза.

## 3D

- Загружается после первой отрисовки, до этого на месте сцены постер.
- Нет WebGL2, включён `Save-Data` или `prefers-reduced-motion` — остаётся постер.
- `frameloop="demand"`, если сцена не двигается сама; вне экрана рендеринг останавливается.
- `dpr` ограничен двумя.
- Модели сжимаются: Draco или Meshopt, текстуры KTX2.
- Сцена, которая живёт между страницами, находится в корневом макете.

## Песочница

Примитивы собираются на странице `/lab`. В `sitemap` её нет, ей ставится `noindex`. Она проверяет
эффекты в одном месте и может стать публичным разделом экспериментов.
