# Security

This is a static site with no accounts, no forms and no server code of its own. The scope is this
repository and the files served at [finchaf.com](https://finchaf.com).

If you find a problem, please report it privately, in Russian or English:

- through GitHub: [**Report a vulnerability**](https://github.com/finchaf/portfolio/security/advisories/new);
- or by mail: [work@finchaf.com](mailto:work@finchaf.com).

Please do not open a public issue or pull request about it first. The same contacts are in
[`security.txt`](https://finchaf.com/.well-known/security.txt).
